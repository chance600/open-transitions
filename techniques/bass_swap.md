# bass_swap

**Bank:** T-002 · **Automatability:** ADOPT · **Confidence:** high

**Source:** null-set-ai-dj (MIT); the single most important 1-beat move in dance mixing

## Signature

```python
bass_swap(a, b, sr)
```

## Spec

Instantaneous low-band handover. a, b equal length; swap at sample 0.

Caller aligns the arrays so index 0 is the downbeat.
