# bass_swap

**Bank:** T-002 · **Automatability:** ADOPT · **Confidence:** high

**Source:** null-set-ai-dj (MIT); the single most important 1-beat move in dance mixing

## Signature

```python
bass_swap(a, b, sr)
```

## Spec

Instantaneous low-band handover. a, b equal length; swap at sample 0.

Caller aligns the arrays so index 0 is the downbeat.

## Axis (Phase 23, genre traditions tranche A)

**Periodic alternation** — inside a long two-track blend, bass
ownership itself can be traded repeatedly: "use the bass eq
controls to switch between the bass parts of each track every 8
or so bars" (DJ TechTools forum, "Transitions In a Mix",
practitioner doctrine, fetched 2026-10-22). The swap becomes a
rhythm at phrase scale — each exchange is this base fired again
on the blend's bar grid, alternating direction, until the blend
resolves to one track. Distinct from drop_chop (WEB-20): there
the FULL drops alternate; here only the low band changes hands
while both tracks keep playing.
