# Contributing to open-transitions

Contributions are welcome — that is the point of this repo. What we
want: new transition techniques, better demos, selector evidence,
and docs. What we do not want: rips of other people's work, or
closed forks that take without giving back.

## How to contribute

1. Open an issue or pull request. Small, reviewable PRs beat big ones.
2. A new technique ships as a spec, not just code: name, parameters
   with units and defaults, when to use / when to avoid, provenance
   (free/public sources only — no paid courses, books, or login-walled
   material), and a demo that renders cleanly.
3. Every technique needs a demo + verification pass before it counts
   as proven. A demo that only passes machine checks is not proven —
   a human has to hear it.
4. Promotion into the registry needs verdict evidence: a human PASS
   (or heart) on a render using the technique. Machine metrics alone
   never promote, and silence never approves.
